Vault Backup

Vault Backup is a private, single-user backup utility operated by the owner of the thalsdj GitHub account.

It uses Rclone to connect to the owner's Google Drive and Restic to create encrypted, versioned backups of personal files. It is not a public service and does not accept other users.

Google Drive access is used to create, read, maintain, and restore the owner's backup repository.
